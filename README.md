# AUTO FORES Landing Page

Landing page orientada a captación de leads para AUTO FORES, enfocada en servicios especializados Land Rover en Bogotá.

## Estructura

/project-root
- index.html
- /css/styles.css
- /js/script.js
- /assets/hero-landrover.svg
- /assets/inspection-landrover.svg

## Funcionalidades
- Hero de conversión con formulario visible sin scroll
- Formulario validado en JavaScript
- Redirección automática a WhatsApp con mensaje prellenado
- Diseño responsive
- CTA flotante de WhatsApp
- Sección de servicios
- Revisión preventiva de 20 puntos
- Testimonios
- Contacto y mapa embebido
- SEO básico

## Uso
1. Sube los archivos a tu repositorio.
2. Abre `index.html` en navegador o despliega en Netlify, Vercel o GitHub Pages.
3. Si deseas cambiar textos, imágenes o colores, edita:
   - `index.html`
   - `css/styles.css`
   - `js/script.js`
